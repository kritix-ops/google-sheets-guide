# The grid model

Every spreadsheet is built from sheets, and each sheet is a grid of cells. A cell has an address: column letter plus row number. In the table below, **B5** is the cell at column B, row 5: the fourth campaign's media buyer, Eitan Kohen. This is the campaign log you will keep coming back to throughout the course.

This first lesson is about the layer underneath every formula: how cell addresses work, what happens when a reference is copied across cells, and the four locking forms (`B5`, `$B5`, `B$5`, `$B$5`) that decide whether a reference walks with you or stays anchored. Get this right and every later lesson reads cleanly. Get this wrong and the whole formulas track is a struggle, because every multi-cell formula in the rest of Track 1 leans on these rules.

## References shift when you copy

When you write `=E2` somewhere, you are storing a *reference* to the cell, not a copy of its value. If `E2` (the spend on the first campaign) changes, your formula updates. Copy the formula somewhere else and the reference shifts too. This is the single most useful behavior in spreadsheets, and the source of about 40% of broken formulas.

The next demo computes profit (revenue minus spend) for the first three campaigns. Type `=F2-E2` in `H2`, drag down: the references walk with you.

## Pinning a reference with `$`

Sometimes the reference should *not* shift when copied. Pin it with `$`. The classic adtech case: a media-buying fee that lives in **one cell** and applies to **every campaign**. Imagine `J1` holds the fee percentage `0.10` (a 10% platform fee on revenue). The formula `=F2*$J$1` computes the fee for one row; copy down and the row reference (`F2` → `F3` → `F4`) shifts, but `$J$1` stays anchored.

<RefDemo
  data={CAMPAIGNS}
  formula="=F2*$J$1"
  formulaCell="H2"
  fillTo="H5"
  expectedFills={["=F3*$J$1", "=F4*$J$1", "=F5*$J$1"]}
  caption="Absolute reference (the $J$1 part) stays glued. Without the dollar signs, the fee cell would walk off and your formulas would silently start multiplying revenue by empty cells."
/>

The four reference forms cover every locking pattern. Each `$` locks one axis: in front of the column letter locks the column; in front of the row number locks the row.

| Form | Column | Row |
|---|---|---|
| `B5` | moves | moves |
| `$B5` | **locked** | moves |
| `B$5` | moves | **locked** |
| `$B$5` | **locked** | **locked** |

## Mixed references

Use one `$` when you want to lock just one axis. The classic case: a spend-vs-revenue table where the row labels (verticals) and column headers (platforms) form a grid, and you want one formula that fills the whole grid.

If you copy it down rows, both stay put because the row is pinned.</>}

## Named ranges

A range expressed as `B2:B13` is fragile. It depends on nobody inserting a row above row 2, on the data ending exactly at row 13, on you remembering what `B2:B13` was when you wrote it. The fix: name the range, refer to it by name. `=AVERAGE(spend)` reads better than `=AVERAGE(E2:E13)`, survives row insertions, and documents intent.

<MiniGrid
  data={CAMPAIGNS}
  highlight={["E2", "E3", "E4", "E5", "E6", "E7", "E8", "E9", "E10", "E11", "E12", "E13"]}
  highlightTone="primary"
  caption="The range E2:E13, named 'spend'. Once named, =SUM(spend) is the address."
/>

To create one: select the range (here `E2:E13`), open **Data > Named ranges**, type `spend` as the name, and click **Done**. The name takes effect immediately, and any formula in the workbook can write `=AVERAGE(spend)` instead of `=AVERAGE(E2:E13)`. Shortcut: with the range selected, type the name straight into the **Name box** (the box to the left of the formula bar) and press Enter.

In the team's actual workbooks, named ranges are everywhere: `media_fee_pct`, `target_roi`, `vertical_lookup`, `current_period`. The pattern is to define them once at the top of a "Config" sheet and reference them from every other formula. When the fee changes from 10% to 12%, you edit one cell, not 200 formulas.

## Used in the wild

In the team's real workbooks, three patterns built on this lesson show up everywhere:

- **The `Config` sheet.** A single tab holding named cells: `media_fee_pct`, `target_roi`, `current_period_start`, `current_period_end`, `usd_to_ils`. Every other sheet in the workbook references these by name. Change the value once, the whole model updates.
- **Cross-platform aggregator formulas.** Each platform sheet has its own raw-data tab. The aggregator references them with a mix of relative refs (per-row) and absolute refs (per-formula constants). Forgetting the `$` is how a `SUMIFS` that "worked yesterday" returns zero today.
- **The "fill down to row 100,000" pattern.** Setting up formulas to handle rows you haven't imported yet. Without `$` discipline, the formulas reference each other in a cascade and break when you actually paste new data in. Lesson 1.10 covers the `ARRAYFORMULA` alternative that sidesteps this entirely.

## Pro pitfalls

- **A range like `B2:B13` walks if rows are inserted above row 2.** Use a named range or a whole-column reference (`B:B` or `B2:B`) when stability matters. For appendable logs, tables (lesson 1.17) are the durable answer.
- **`B:B` is convenient but slow on big sheets.** It scans every cell in the column. Bounded ranges (`B2:B10000`) are usually the right middle ground.
- **Copy-paste of formulas is reference math, not text math.** `=B5` pasted into `D2` does not say "B5"; it computes "the cell two columns to my left, three rows down" relative to D2 and resolves accordingly. Pasting as values (`Ctrl+Shift+V`) breaks the link.
- **`F4` (Windows) / `Cmd+T` (Mac)** cycles through reference forms in the formula bar. Muscle memory worth investing in.
- **Forgetting the `$` on a lookup-table range** is the most common cause of `#N/A` cascades. The first row of a fill-down looks correct; rows below silently break as the table walks off itself.
- **Mixed references (`$B5`, `B$5`) are the right tool for grid formulas** where a single formula needs to fill both across columns AND down rows. Plan which axis stays anchored before you write the formula.

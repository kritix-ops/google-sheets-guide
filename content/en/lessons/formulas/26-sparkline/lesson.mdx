# SPARKLINE: charts inside cells

`SPARKLINE` draws a tiny chart inside a single cell. No chart object, no resizing, no separate render: the cell *is* the chart. For a dashboard with one row per buyer or per vertical, a sparkline column gives instant visual context without burning screen real estate.

## Basic syntax

```
=SPARKLINE(data_range)
=SPARKLINE(data_range, {"option1", value1; "option2", value2; ...})
```

The first argument is the data: usually a row or column of numbers. The second argument is an options object specifying chart type, colors, and axis behavior.

<FunctionRef name="SPARKLINE" />

The simplest call:

```
=SPARKLINE(B2:B8)
```

Draws a default line chart from those 7 values. Resize the row to make the sparkline taller; resize the column to make it wider.

## The four chart types

| Type | Use when |
|---|---|
| `line` (default) | Trends over time, continuous data |
| `column` | Comparing discrete categories |
| `bar` | Single-segment progress bar (one or two values) |
| `winloss` | Outcomes where direction matters more than magnitude |

```
=SPARKLINE(B2:B8, {"charttype","line"})
=SPARKLINE(B2:B8, {"charttype","column"})
=SPARKLINE(B2:B8, {"charttype","bar"})
=SPARKLINE(B2:B8, {"charttype","winloss"})
```

## The options object

Options are passed as a 2-column array. Pairs are separated by `;` (row separator), name and value by `,` (column separator):

```
=SPARKLINE(B2:B8, {
  "charttype", "line";
  "color", "blue";
  "linewidth", 2;
  "ymin", 0
})
```

Common options:

| Option | Values | Use |
|---|---|---|
| `charttype` | line, column, bar, winloss | Pick the chart type |
| `color` | named color or hex | Line/bar/column color |
| `color1` / `color2` | colors | For winloss: positive vs negative bars |
| `linewidth` | number | Line thickness for line charts |
| `ymin` / `ymax` | numbers | Force Y-axis bounds |
| `firstcolor`, `lastcolor`, `highcolor`, `lowcolor`, `negcolor` | colors | Highlight specific points (column/winloss) |
| `axis` | TRUE/FALSE | Show baseline at y=0 |
| `rtl` | TRUE/FALSE | Right-to-left display (for date axes that count down) |

## Adtech: per-buyer revenue trend

A dashboard with one row per buyer and a 7-day revenue trend in one cell:

| Buyer | Total revenue | 7-day trend |
|---|---|---|
| Yoav Cohen | $4,310 | sparkline of last 7 days |
| Sarah Levi | $3,820 | sparkline |
| David Mizrahi | $5,640 | sparkline |

Formula in the trend column (assuming each buyer's daily revenue is in a row 7 columns wide):

```
=SPARKLINE(B2:H2, {"charttype","line"; "color","#4285F4"; "linewidth",2})
```

Drag down for each buyer. At a glance you see who's trending up, who's flat, who's spiking on a single day.

## Win/loss for ROI bands

A winloss sparkline draws a small bar above (positive) or below (negative) the baseline for each value. Magnitude is ignored; only direction matters.

```
=SPARKLINE(B2:H2, {"charttype","winloss"; "color1","green"; "color2","red"; "negcolor","red"})
```

For a row of daily ROIs, this becomes a "8 wins, 4 losses" bar pattern at a glance: useful for quick consistency checks without quoting numbers.

## Pro pitfalls

- **Sparklines render in the cell only.** They don't appear in screenshots taken via the Sheets API in some versions, and don't appear in `print to PDF` if the row height is too small. Always test before depending on a sparkline-heavy dashboard for stakeholder reports.
- **The options array uses semicolons for row separators.** A typo using comma instead breaks the formula silently with a confusing parse error. Keep the pattern: name comma value, then semicolon, then next pair.
- **Empty cells in the data range** are ignored by default: but a single non-numeric value (like `#N/A` from a broken lookup) breaks the whole sparkline. Wrap the data with `IFERROR` (lesson 9) before passing it.
- **Color names** are case-sensitive in some cases and inconsistent across charts. Hex codes (`"#4285F4"`) are safer than names (`"blue"` vs `"Blue"`).
- **Y-axis defaults to data range.** A sparkline of values 95-100 looks identical to one of 5-100 unless you set `ymin` and `ymax`. For consistent visual comparison across rows, lock the bounds.
- **Sparklines don't auto-update on conditional formatting.** They render based on data, not on formatting state. If you want "trends colored red when below threshold," compute the colors in the options programmatically.
- **The data range can be a column or row** but not a 2D grid. If you want multiple series, you can't.

## Used in the wild

- **Per-buyer or per-vertical trend column** in dashboards. One cell, instant visual context, dragable across the whole list.
- **ROI consistency winloss bars.** Daily ROI as a row of green/red ticks: flags inconsistent buyers without dumping numbers.
- **Period-over-period sparkline.** Last 30 days of spend as one tiny chart per row of the report.
- **Goal tracking bars.** A bar-type sparkline showing % progress to monthly goal, with `ymax` set to the goal value.
- **A/B test outcome strip.** Win/loss across N test arms, color-coded green/red, in a single cell of the experiment summary.

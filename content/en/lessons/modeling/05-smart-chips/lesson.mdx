# Drop-downs and smart chips: people, file, finance, date, place, YouTube, dropdown chips

Lesson 2.4 covered the drop-down half of `Data → Data validation`: closed lists, ranges, custom formulas. This lesson is about the other half of the controlled-input story: **smart chips**, the rich `@`-mention inserts that pin a person, a file, a place, a finance ticker, or a calendar date into a single cell. A buyer name typed as text is just a string. The same name as a person chip is a link to that person's profile, their email, their availability: hover and you see it. The cell still looks like one cell. Underneath, it's a structured reference to something outside the spreadsheet.

Think of a chip as the cell's superpower mode. The display is still tiny, the semantics are infinitely richer. The team uses chips wherever a piece of data points at something living elsewhere: a person on Slack, a folder in Drive, a calendar event, a vendor's stock ticker. The chip turns a 30-second context switch (open Drive, search, click) into a one-click hover.

## The chip types you'll actually use

Sheets supports more chip kinds than this, but in adtech work the same handful keep showing up:

| Chip | What it pins | Adtech context |
|---|---|---|
| Person | A Workspace user (name, email, profile, Calendar) | Owner of an `Aggregator` tab; on-call media buyer per row |
| File | A Drive file (Sheet, Doc, Slide, Form, Folder) | Pin the source workbook next to its IMPORTRANGE aggregator; link the creative folder per campaign |
| Finance | A stock ticker, mutual fund, or currency pair | Competitor stock signals tied to weekly budget calls |
| Place | A Google Maps location | Geo-targeted creative review notes (the city the ad is running in) |
| Date / Calendar event | A date or an event from your Calendar | Launch dates, freshness markers on dashboards, media-plan milestones |
| YouTube video | A YouTube URL with thumbnail and hover preview | Pin a creative review URL per row; pin the platform's "best practices" walkthrough next to a media-plan tab |
| Dropdown | A `Data validation` list rendered as an inline pill (lesson 2.4) | Vertical, country, platform, status, any closed list where the chip styling reads cleaner than the dropdown arrow |

Person and File carry most of the weight in real workbooks. YouTube and Dropdown chips are newer (the dropdown pill rendering shipped in 2024) and worth knowing because they replace patterns the team used to handle with hyperlinks and bare validation cells.

### YouTube and Dropdown chips, in more detail

The **YouTube video chip** is inserted the same way as a file chip: type `@` and paste a YouTube URL (or search by video title) and pick the result. The chip renders as a small pill with the video's thumbnail visible on hover, and clicking the pill opens the video in a side panel without leaving the workbook. The team uses it on the creative-review tracker: each row's `Creative URL` cell holds a YouTube chip pointing at the platform's submitted video asset. Reviewers hover to see the thumbnail and click to watch, all without bouncing into a new tab.

The **Dropdown chip** is what happens when a `Data validation` rule is configured with `Display style: chip` (the 2024 rendering option in the validation dialog, covered in lesson 2.4). The cell no longer shows a dropdown arrow on the right edge; instead the selected value renders as an inline pill, often color-coded. Functionally it is still the same validation list, with the same Reject input and the same valid values. Visually it reads like a status badge, which is why it has taken over from plain validation in dashboards: a `Status: Active`, `Status: Paused`, `Status: Archived` column reads at a glance when each value is its own colored chip. Cross-reference lesson 2.4 for the validation half of the setup; the chip is purely a rendering choice on top of it.

## Inserting a chip: the @-mention pattern

Inside any cell, type `@` and Sheets opens a chip-picker. The picker filters as you type:

- `@yoav` filters to people whose name matches `yoav`. Pick `Yoav Cohen` and the cell now holds a person chip linked to his Workspace identity.
- `@May 10` filters to dates and offers a "May 10, 2026" date chip.
- `@AAPL` filters to finance and offers the Apple stock ticker chip.
- `@Master campaign log` filters to Drive files matching that title.

The chip renders as a small pill with the entity's name and a hover preview. The cell's underlying text is just `@`. The display text and the link target both live in chip metadata, not in the cell value.

There's a second insertion path that catches people out: paste a Drive URL directly into a cell. Sheets shows a prompt "Replace with a smart chip?". Accept and you get a file chip. Dismiss (or paste while the prompt times out) and you get a plain hyperlink string. Both are clickable; only one is searchable and structured.

## How the API sees a chip

Each chip is a `ChipRun` attached to the cell. A run carries a `startIndex` (the character position in the cell where the chip sits) plus a `Chip` payload that's either a person chip or a rich-link chip:

```
A1 = "@"           // the cell value is just the @ placeholder
chipRuns[0]:
  startIndex: 0
  chip:
    personProperties:
      email: "yoav.cohen@flexelent.com"
```

Or for a file chip:

```
B2 = "@"
chipRuns[0]:
  startIndex: 0
  chip:
    richLinkProperties:
      uri: "https://docs.google.com/spreadsheets/d/abc123"
      mimeType: "application/vnd.google-apps.spreadsheet"
```

`mimeType` is what tells you the chip's subtype: `application/vnd.google-apps.spreadsheet` for a Sheet, `application/vnd.google-apps.document` for a Doc, `application/vnd.google-apps.folder` for a Drive folder, and so on. Place chips, finance chips, and calendar chips have their own bespoke `mimeType` values, but the `vnd.google-apps.*` family covers every Drive file the team links daily.

## Used in the wild

In the team's actual workbooks:

- **Every `Aggregator` tab has an Owner column with person chips.** When something breaks at 11 PM, the on-call rotation `@`-mentions the chip and the right person gets paged. A name in plain text doesn't page anyone.
- **The master campaign log has a `Source folder` column with file chips.** Each row's chip points at the Drive folder holding the creatives, the landing-page screenshots, and the brief. One click from the row to the artifacts.
- **Dashboards carry a freshness marker.** A header cell with a date chip says "Data through May 9, 2026" and the chip becomes a Calendar link if the team wants to schedule a review.
- **Per-campaign owner attribution.** When a row's `Buyer` cell is a person chip, filtering the sheet by buyer still works because Sheets indexes the chip's display name. The chip is strictly an upgrade over plain text in this case.

## Pro pitfalls

- **Chips don't survive `Paste special → Values only`.** That paste mode strips the chip and leaves the bare `@`. If you build a workbook by pasting from another spreadsheet, you'll need to re-enter every chip on the destination side. Plain copy-paste preserves chips; values-only doesn't.
- **Searching for a person's name with `FIND` or `REGEXMATCH` doesn't match.** The cell's underlying text is `@`. The name `Yoav Cohen` lives in the chip's `personProperties`, not in the cell value. `FIND("Yoav", A2)` returns `#VALUE!`. To search across chips, you need the API or an Apps Script.
- **Chips break for viewers outside the Workspace domain.** A person chip for `@yoav.cohen@flexelent.com` shows up to a contractor with a personal Gmail as a chip pill, but clicking it leads to "you don't have access". File chips have the same failure mode if the linked Drive file isn't shared with the viewer.
- **`IMPORTRANGE` does not bring chips across** (lesson 1.27). When the `Aggregator` tab pulls from `Raw - Taboola` via `IMPORTRANGE`, the imported cells contain whatever text the source had at the chip position, which is just `@`. Chips have to be recreated on the consuming sheet, or the source data needs to live in plain columns alongside.
- **Sorting a column of person chips works, but the sort key is the chip's display name, not the email.** Two buyers with the same first name (`Yoav Cohen` and `Yoav Levi`) sort by full display name. If you need email-precision sort, add a hidden helper column with the email pulled out via Apps Script.
- **A chip in a `QUERY` source range becomes the bare `@`** in the QUERY output. QUERY reads the cell's text value, not the chip metadata. Aggregating chip-bearing columns means losing the chip in the result.

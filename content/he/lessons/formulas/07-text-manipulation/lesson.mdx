# מניפולציה של טקסט: LEFT, RIGHT, MID, FIND, SUBSTITUTE

מידע אמיתי מגיע מלוכלך, במיוחד אחרי שעבר בחצי תריסר פלטפורמות לפני שמגיע אליכם. שמות verticals עם סיומות לא עקביות, קודי קמפיין דחוסים במטא-דאטה, שמות media buyers שצריך לקצר בשביל לג'נד של גרף. פונקציות חיתוך הטקסט מטפלות בניקיון היומיומי. פונקציות העיצוב (UPPER, LOWER, TRIM) משיעור 3 מטפלות ב-case וב-whitespace, השיעור הזה מטפל בחיתוך והחלפה.

## LEFT, RIGHT, MID: חילוץ לפי מיקום

שלוש פונקציות אחיות, כל אחת מקבלת מחרוזת ומספר.

- `LEFT(text, n)` מחזיר את `n` התווים הראשונים
- `RIGHT(text, n)` מחזיר את `n` התווים האחרונים
- `MID(text, start, n)` מחזיר `n` תווים החל ממיקום `start` (1-indexed)

שמות ה-verticals של הצוות כולם מסתיימים ב-`" PR"` לפי הקונבנציה. כדי לקבל רק את הנושא, להוריד את 3 התווים האחרונים, צריך `LEFT` בשילוב עם `LEN` (הוצג בשיעור 3).

## FIND: לאתר תו

`FIND(needle, haystack, [start])` מחזיר את ה**מיקום** של ההתאמה הראשונה. הוא 1-indexed ורגיש ל-case. `SEARCH` הוא האח שלא רגיש ל-case, באותה צורה אבל סובלני להבדלי case. מושכים ל-`SEARCH` כשטקסט המקור מגיע מ-feeds לא עקביים במעלה הזרם; מושכים ל-`FIND` כש-case משנה (פירסור של קודי הקמפיין של הצוות שמבדילים בין "PR" ל-"pr").

מרכיבים את `FIND` עם `LEFT`/`RIGHT`/`MID` כדי לחתוך לפי מפריד ידוע במקום מיקום ידוע. ל-vertical כמו `"Used Cars PR"`, המילה הראשונה היא כל מה שמשמאל לרווח הראשון, אבל המיקום משתנה לפי שם ה-vertical.

## SUBSTITUTE: להחליף תת-מחרוזת באחרת

`SUBSTITUTE(text, old, new, [occurrence])` מחליף כל מופע של `old` ב-`new`. מעבירים מספר `occurrence` כדי להחליף רק את המופע ה-n. שימושי לקיצור שמות לגרפים, לנרמול מפרידים לא עקביים או להסרת תווים לא רצויים. כרטיס ה-reference המלא הוצג בשיעור 3 לצד `TRIM`; פה אנחנו מראים את הווריאנט שמודע-למיקום שלו דרך ה-occurrence_number האופציונלי.

## איך בוחרים

| מטרה | מה בוחרים |
|---|---|
| לקחת את N התווים הראשונים/אחרונים | `LEFT` / `RIGHT` |
| לקחת N תווים ממיקום ידוע | `MID` |
| למצוא מיקום של תו | `FIND` (רגיש ל-case) או `SEARCH` |
| להחליף תת-מחרוזת בכל מופע | `SUBSTITUTE` |
| להחליף לפי מיקום | `REPLACE` |
| לספור תווים | `LEN` |
| חילוץ מבוסס תבנית | `REGEXEXTRACT` (שיעור 16 מכסה regex לעומק) |

## נפוץ בשטח

- **הורדת הסיומת " PR" מכל עמודת vertical.** או כ-LEFT+LEN inline או כ-SUBSTITUTE לפי סיומת. נעשה פעם אחת בראש טאב "clean" דרך ARRAYFORMULA, ככה שכל הגיליונות במורד הזרם מקבלים את הגרסה רק-עם-נושא.
- **פירסור קודי קמפיין.** קודים כמו `Taboola_UsedCarsPR_DesktopUS_2026-05` משרשרים FIND+MID לחילוץ פלטפורמה, vertical, תג קהל, תקופה, בדרך כלל בונים 4 עמודות ליד עמודת הקוד.
- **קיצור שמות media buyers ללג'נדים של גרפים.** SUBSTITUTE של שם המשפחה לאות, או LEFT(buyer, FIND(" ", buyer)-1) כדי לקחת רק את השם הפרטי.
- **נרמול מפתחות join.** משלבים UPPER/LOWER (שיעור 3) עם TRIM ו-SUBSTITUTE לפני XLOOKUP בין גיליונות, במיוחד כששני המקורות הגיעו מפלטפורמות שונות עם קונבנציות שונות.

## מלכודות מקצועיות

- **`FIND` מחזיר `#VALUE!` כשאין התאמה.** אם מפרסרים מפריד שאולי לא קיים, עוטפים ב-`IFERROR` (שיעור 9): <code>=IFERROR(LEFT(A2, FIND(" ", A2)-1), A2)</code>.
- **`SUBSTITUTE` רגיש ל-case.** `=SUBSTITUTE("Cohen Cohen", "cohen", "C.")` מחזיר "Cohen Cohen" בלי שינוי. או מעבירים את ה-case הנכון או עוטפים את שני הצדדים ב-`LOWER()`.
- **`LEFT(A2, LEN(A2)-3)` מחזיר זבל למחרוזות קצרות מ-3 תווים.** הוא מחזיר LEFT עם ספירה שלילית, מה ששוגה. הוסיפו משמר עם `IF(LEN(A2)<=3, "", LEFT(...))` למידע מבולגן.
- **Whitespace בלתי נראה.** `=LEN(A2)` למה שנראה כמו "Yoav" יכול להחזיר 5 אם יש רווח אחרי. עושים TRIM קודם בזמן פירסור.

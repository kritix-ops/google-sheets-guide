# LAMBDA: הגדרת פונקציות משלכם בתוך נוסחה

`LAMBDA` מאפשר להגדיר פונקציה inline. הוא מקבל שם של parameter אחד או יותר וגוף שמשתמש בהם, ומחזיר פונקציה שאפשר לקרוא לה. ברגע שיש LAMBDA, או שמפעילים אותו מיד, או שמעבירים אותו ל-helper כמו `MAP` או `REDUCE` (השיעור הבא), או שומרים אותו כ-**named function** לשימוש חוזר ברמת הצוות (שיעור 21).

LAMBDA הוא היסוד לכל עבודת הנוסחאות המודרנית ב-Sheets. אפשר לבנות מחדש את SUMIF, לכתוב מחשבונים פר שורה, להגדיר KPI ייעודיים לצוות, ולהימנע מהעתקה והדבקה של נוסחאות מסובכות לאורך 400 תאים.

## התחביר

```
LAMBDA(param1, param2, ..., body)
```

ה-parameters מופיעים קודם, ואז הגוף שמשתמש בהם. שמות ה-parameters הם מקומיים, הם קיימים רק בתוך הגוף.

<FunctionRef name="LAMBDA" />

```
=LAMBDA(spend, revenue, (revenue - spend) / spend)
```

זה הכל. אבל שימו לב: שום דבר לא מחושב פה. LAMBDA חשוף מחזיר פונקציה, לא ערך. אם מכניסים אותו לתא, Sheets מציג `#CALC!` כי לנוסחה אין ערך החזרה להציג.

## קריאה ל-LAMBDA

כדי לקבל ערך, צריך **להפעיל** אותו. ההפעלה הפשוטה ביותר היא inline, עוטפים את ה-parameters בסוגריים נוספים אחרי ה-LAMBDA:

```
=LAMBDA(spend, revenue, (revenue - spend) / spend)(100, 250)
```

הנוסחה הזו מחזירה `1.5`. ה-`(100, 250)` בסוף מעביר `spend=100` ו-`revenue=250` לתוך הגוף.

הדפוס הזה לבדו רק לעיתים נדירות שימושי. אפשר פשוט לכתוב `=(250-100)/100` ולוותר על ה-LAMBDA. LAMBDA משתלם כשהגוף משמש לקלטים רבים, או כשנותנים לפונקציה שם עם LET או כ-named function.

## LAMBDA + LET: שם לפונקציה

`LET` מאפשר לתת שם לערך או לפונקציה בתוך נוסחה. בשילוב עם LAMBDA, מגדירים מחשבון פעם אחת ומשתמשים בו לכמה קלטים באותו תא:

```
=LET(
  roi, LAMBDA(s, r, (r-s)/s),
  roi(100, 250) + roi(200, 600)
)
```

`roi` הוא עכשיו פונקציה בתוך ה-LET. אפשר לקרוא לה כמה פעמים שרוצים. התוצאה פה היא `1.5 + 2 = 3.5`.

באדטק, ככה בונים מחשבונים פר נוסחה: מגדירים `cpc`, `cpm`, `roas` בתוך LET אחד, ואז משרשרים אותם.

## למה זה שווה את הטרחה באדטק?

שלושה רווחים אמיתיים:

1. **מחשבונים בנוסחה אחת.** במקום תא אחד עם `=B2*0.95` ועוד אחד עם `=B2-fee`, מגדירים LAMBDA בתוך LET שמטפל בחישוב במקום אחד. עורכים פעם אחת, כל ביטוי תלוי מתעדכן.
2. **העברה ל-MAP/REDUCE.** השיעור הבא (MAP, REDUCE, SCAN, BYROW, BYCOL, MAKEARRAY) בנוי על LAMBDA. `=MAP(A2:A100, LAMBDA(x, x*1.1))` מחיל markup של 10% על כל ערך בנוסחה אחת. בלי גרירה למטה, בלי סיכון לשכוח שורה.
3. **Named functions.** שיעור 21 מכסה הפיכת LAMBDAs ל-named functions לשימוש חוזר: `=ROI(spend, revenue)` הופך לפונקציה אמיתית בגיליון של הצוות, עם תיעוד ואימות parameters. אחרי שמגדירים פעם אחת, כל dashboard משתמש בה באופן עקבי.

## מלכודות

- **LAMBDA חשוף בתא מציג `#CALC!`.** זו פונקציה, לא ערך. חייבים להפעיל אותה (`(args)`) או להעביר אותה ל-helper שקורא לה.
- **Parameters מסתירים named ranges.** אם יש named range בשם `spend` וכותבים `LAMBDA(spend, spend*2)`, ה-parameter מנצח בתוך הגוף. בדרך כלל בסדר, מדי פעם מפתיע.
- **אין closures על named ranges מבחוץ.** בתוך גוף LAMBDA, אפשר להפנות לתאים (`A2`, `B5:B10`) ולפונקציות מובנות, אבל אי אפשר להפנות למשתנים מ-LET חיצוני אלא אם מעבירים אותם במפורש. כדאי להשאיר LAMBDAs סגורים על ה-parameters שלהם בלבד.
- **רקורסיה ב-LAMBDA נתמכת אבל מוגבלת.** אפשר לקרוא ל-named function מתוך הגוף שלה עצמה (שיעור 21), אבל עומק הרקורסיה מוגבל. Sheets עוצר אחרי כמה מאות רמות כדי למנוע נוסחאות מתפרצות.
- **הגוף הוא ביטוי אחד.** אין נקודה-פסיק, אין statements. אם צריך ערכי ביניים, מקננים LET *בתוך* הגוף: `LAMBDA(x, LET(y, x*2, y+1))`.
- **LAMBDAs אנונימיים קשים ל-debug.** LAMBDA של 200 תווים בתוך MAP הוא לא קריא. מקדמים אותו ל-named function (שיעור 21) ברגע שהוא מפסיק להיכנס בשורה אחת.

## נפוץ בשטח

- **מחשבונים חד פעמיים ב-dashboards.** `=LET(roi, LAMBDA(s,r,(r-s)/s), roi(SUM(Campaigns[Spend]), SUM(Campaigns[Revenue])))` מחשב ROI כללי בתא יחיד.
- **Lookups עם parameters.** מגדירים `LAMBDA(buyer, vertical, SUMIFS(...))` בתוך LET, ואז קוראים לזה עם זוגות שונים של buyer/vertical כדי לבנות סיכום inline קצר.
- **אבני בניין ל-MAP/REDUCE.** כמעט כל שימוש אמיתי ב-MAP וב-REDUCE (שיעור הבא) מקבל LAMBDA כארגומנט הפונקציה.
- **Named functions** (שיעור 21). הצוות מגדיר את `ROI(spend, revenue)`, `ROAS(spend, revenue)`, `EFFECTIVE_CPC(spend, clicks)` פעם אחת ומשתמש בהם בכל מקום. הגוף הוא LAMBDA.

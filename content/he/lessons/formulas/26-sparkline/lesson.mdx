# SPARKLINE: charts בתוך תאים

dashboard עובד בדרך כלל מכיל שורה אחת לכל media buyer, לכל vertical, או לכל קמפיין, והעין רוצה קו מגמה לכל שורה בלי לפתוח chart נפרד. `SPARKLINE` הוא הפתרון: הוא מצייר chart זעיר בתוך תא הנוסחה עצמו. אין אובייקט chart, אין resize, אין שכבת render נפרדת. התא הוא ה-chart.

לצוות שמריץ חמישים media buyers בחמש פלטפורמות, עמודת sparkline הופכת קיר של מספרים לויזואל במסך אחד. רואים מי מטפס, מי שטוח, מי קפץ ביום שלישי בודד. העלות היא נוסחה אחת לשורה. התשואה היא שבעל עניין יכול לסרוק את הדוח בעשר שניות במקום לפזול על סיכומים.

## ה-sparkline המינימלי

הקריאה הפשוטה ביותר מעבירה טווח בודד של מספרים:

```
=SPARKLINE(B2:B8)
```

סוג chart ברירת מחדל הוא `line`. גובה השורה שולט בפיקסלים אנכיים; רוחב העמודה שולט בפיקסלים אופקיים. זו כל הנוסחה. הבחירות המעניינות חיות בארגומנט השני: אובייקט האפשרויות.

## ארבעת סוגי ה-chart

| סוג | מתי משתמשים |
|---|---|
| `line` (ברירת מחדל) | מגמות לאורך זמן, נתונים רציפים |
| `column` | השוואה בין קטגוריות בדידות זו לצד זו |
| `bar` | סרגל התקדמות בודד (ערך אחד או שניים) |
| `winloss` | תוצאות שבהן הכיוון חשוב יותר מהגודל |

```
=SPARKLINE(B2:B8, {"charttype","line"})
=SPARKLINE(B2:B8, {"charttype","column"})
=SPARKLINE(B2:B8, {"charttype","bar"})
=SPARKLINE(B2:B8, {"charttype","winloss"})
```

בוחרים את סוג ה-chart לפי *השאלה שהשורה עונה עליה*. מגמת revenue יומית? `line`. spend לפי פלטפורמה? `column`. התקדמות ליעד חודשי? `bar`. ימים שבהם ROI היה חיובי לעומת שלילי? `winloss`.

## אובייקט האפשרויות

האפשרויות מועברות כמערך דו-עמודתי. בתוך הסוגריים המסולסלים, מפרידים זוגות ב-`;` (מפריד שורה) ואת שם האפשרות מערכה ב-`,` (מפריד עמודה).

```
=SPARKLINE(B2:B8, {
  "charttype", "line";
  "color", "#4285F4";
  "linewidth", 2;
  "ymin", 0
})
```

אפשרויות נפוצות:

| אפשרות | ערכים | שימוש |
|---|---|---|
| `charttype` | line, column, bar, winloss | בחירת סוג ה-chart |
| `color` | שם צבע או hex | צבע ה-line/bar/column |
| `color1` / `color2` | צבעים | ל-winloss: סרגלים חיוביים מול שליליים |
| `linewidth` | מספר | עובי הקו ל-line charts |
| `ymin` / `ymax` | מספרים | אילוץ גבולות ציר Y |
| `firstcolor`, `lastcolor`, `highcolor`, `lowcolor`, `negcolor` | צבעים | הדגשת נקודות ספציפיות |
| `axis` | TRUE/FALSE | הצגת קו בסיס ב-y=0 |
| `rtl` | TRUE/FALSE | תצוגה מימין לשמאל |

## Win/loss לעקביות ROI

sparkline של winloss מצייר סרגל קטן מעל (חיובי) או מתחת (שלילי) לקו הבסיס לכל ערך. הגודל מתעלמים ממנו. רק הכיוון חשוב.

```
=SPARKLINE(B2:H2, {"charttype","winloss"; "color1","green"; "color2","red"; "negcolor","red"})
```

עבור שורה של ROI יומי, זה הופך לדפוס סרגלים של "5 wins, 2 losses" במבט מהיר. שימושי לבדיקות עקביות מהירות: media buyer עם שבעה ירוקים מנצח media buyer עם חמישה ירוקים ושני אדומים גדולים, גם אם סך השבוע של ה-ROI שלהם זהה.

## נעילת ציר Y להשוואה הוגנת

sparkline של ערכים 95-100 נראה זהה לאחד של 5-100 כי ציר Y מתאים את עצמו אוטומטית לנתונים. בין שורות ב-dashboard, ההתאמה האוטומטית הזו מטעה: drift קטנטן נראה זהה לקפיצה פי עשרה.

```
=SPARKLINE(B2:H2, {"charttype","line"; "ymin",0; "ymax",1000})
```

עם `ymin` ו-`ymax` מוגדרים לאותם גבולות בכל השורות, ה-sparklines נעשים בני השוואה ישירה. הקו של $400-500 של Sarah נשאר קטן בתחתית בזמן שהקפיצה ל-$1,000 של David ממלאת את התא. זו התמונה שבאמת רוצים שבעלי העניין יראו.

## מלכודות מקצועיות

- **קוריוזים ב-render בייצוא.** Sparklines מתרנדרים בגריד החי אבל לפעמים נעלמים מהדפסת PDF או מ-screenshots דרך ה-Sheets API. בודקים את מסלול הייצוא *לפני* שמסתמכים על dashboards עתירי sparkline לדוחות לבעלי עניין.
- **מערך האפשרויות משתמש ב-`;` בין זוגות וב-`,` בתוך כל זוג.** החלפה ביניהם שוברת את הנוסחה עם parse error מבלבל. הדפוס הוא: `name, value; name, value; name, value`.
- **ערכים לא מספריים מרעילים את ה-chart.** `#N/A` מ-lookup שבור, `"#REF!"` מטווח שנמחק, או מחרוזת טקסט בטווח מספרי יכשילו את כל ה-sparkline. עוטפים נתונים upstream ב-`IFERROR` (שיעור 9) או ב-`IFNA` לפני העברה.
- **שמות צבעים לא עקביים.** `"blue"` עובד, `"navy blue"` לא. קודי hex (`"#4285F4"`) בטוחים יותר ועקביים בצוות.
- **ציר Y מוגדר כברירת מחדל לטווח הנתונים.** שני sparklines עם ערכים מוחלטים שונים מאוד יכולים להיראות זהים בלי `ymin`/`ymax` נעולים. להשוואה הוגנת בין שורות, מגדירים את הגבולות במפורש.
- **בלי נתונים דו-ממדיים.** טווח הנתונים חייב להיות שורה או עמודה בודדת. כמה סדרות ב-sparkline אחד לא נתמך. אם צריך את זה, משתמשים באובייקט chart אמיתי.
- **Conditional formatting לא מתפשט.** Sparklines מתרנדרים מטווח הנתונים, לא מעיצוב התא. "צבע אדום מתחת לסף" צריך להיות מחושב באובייקט האפשרויות, לא ב-CF rule של התא.
- **מקורות נתונים נדיפים.** אם ה-sparkline שואב מ-`IMPORTRANGE` (שיעור 1.27) שמתעכב, ה-chart יתעכב איתו. מצב refresh הוא בעיית המקור upstream; ה-sparkline פשוט מצייר מה שיש.

## נפוץ בשטח

- **עמודת מגמה לכל media buyer או לכל vertical.** תא אחד, הקשר ויזואלי מיידי, ניתן לגרירה לאורך כל הרשימה. dashboard ה-standup של יום שני של הצוות נשען על זה.
- **סרגלי winloss לעקביות ROI.** ROI יומי כשורה של סימני ירוק/אדום. מסמן media buyers לא עקביים בלי לזרוק מספרים לשיחה.
- **sparkline של תקופה מול תקופה.** 30 הימים האחרונים של spend לכל פלטפורמה כ-chart זעיר אחד לכל שורה בדוח סיכום הפלטפורמות.
- **סרגלי מעקב יעדים.** sparkline מסוג bar שמראה אחוז התקדמות ליעד חודשי, עם `ymax` נעול לערך היעד. הסרגל מתמלא ככל שהחודש מתקדם.
- **רצועת תוצאות A/B test.** Win/loss בין N זרועות test, צבועים ירוק/אדום, בתא בודד של טבלת סיכום הניסוי.

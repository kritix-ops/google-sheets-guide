# SPARKLINE: charts בתוך תאים

`SPARKLINE` מצייר chart זעיר בתוך תא בודד. אין אובייקט chart, אין resize, אין render נפרד. התא *הוא* ה-chart. ל-dashboard עם שורה אחת לכל media buyer או לכל vertical, עמודה של sparkline נותנת הקשר ויזואלי מיידי בלי לבזבז שטח מסך.

## תחביר בסיסי

```
=SPARKLINE(data_range)
=SPARKLINE(data_range, {"option1", value1; "option2", value2; ...})
```

הארגומנט הראשון הוא הנתונים, בדרך כלל שורה או עמודה של מספרים. הארגומנט השני הוא אובייקט אפשרויות שמגדיר את סוג ה-chart, צבעים, והתנהגות הצירים.

הקריאה הפשוטה ביותר:

```
=SPARKLINE(B2:B8)
```

מצייר line chart ברירת מחדל מ-7 הערכים האלה. שינוי גובה השורה מגדיל את ה-sparkline; שינוי רוחב העמודה מרחיב אותו.

## ארבעת סוגי ה-chart

| סוג | מתי משתמשים |
|---|---|
| `line` (ברירת מחדל) | מגמות לאורך זמן, נתונים רציפים |
| `column` | השוואה בין קטגוריות בדידות |
| `bar` | סרגל התקדמות בודד (ערך אחד או שניים) |
| `winloss` | תוצאות שבהן הכיוון חשוב יותר מהגודל |

```
=SPARKLINE(B2:B8, {"charttype","line"})
=SPARKLINE(B2:B8, {"charttype","column"})
=SPARKLINE(B2:B8, {"charttype","bar"})
=SPARKLINE(B2:B8, {"charttype","winloss"})
```

## אובייקט האפשרויות

האפשרויות מועברות כמערך דו-עמודתי. זוגות מופרדים ב-`;` (מפריד שורה), שם וערך ב-`,` (מפריד עמודה):

```
=SPARKLINE(B2:B8, {
  "charttype", "line";
  "color", "blue";
  "linewidth", 2;
  "ymin", 0
})
```

אפשרויות נפוצות:

| אפשרות | ערכים | שימוש |
|---|---|---|
| `charttype` | line, column, bar, winloss | בחירת סוג ה-chart |
| `color` | שם צבע או hex | צבע ה-line/bar/column |
| `color1` / `color2` | צבעים | ל-winloss: סרגלים חיוביים מול שליליים |
| `linewidth` | מספר | עובי הקו ל-line charts |
| `ymin` / `ymax` | מספרים | אילוץ גבולות ציר Y |
| `firstcolor`, `lastcolor`, `highcolor`, `lowcolor`, `negcolor` | צבעים | הדגשת נקודות ספציפיות (column/winloss) |
| `axis` | TRUE/FALSE | הצגת קו בסיס ב-y=0 |
| `rtl` | TRUE/FALSE | תצוגה מימין לשמאל (לצירי תאריך שסופרים אחורה) |

## Win/loss לפסי ROI

sparkline של winloss מצייר סרגל קטן מעל (חיובי) או מתחת (שלילי) לקו הבסיס לכל ערך. הגודל מתעלמים ממנו; רק הכיוון חשוב.

```
=SPARKLINE(B2:H2, {"charttype","winloss"; "color1","green"; "color2","red"; "negcolor","red"})
```

עבור שורה של ROI יומי, זה הופך לדפוס סרגלים של "8 wins, 4 losses" במבט מהיר. שימושי לבדיקות עקביות מהירות בלי לצטט מספרים.

## מלכודות מקצועיות

- **Sparklines מצוירים רק בתוך התא.** הם לא מופיעים ב-screenshots שמצולמים דרך ה-Sheets API בגרסאות מסוימות, ולא מופיעים ב-`print to PDF` אם גובה השורה קטן מדי. תמיד לבדוק לפני שמסתמכים על dashboard עתיר sparklines לדוחות לבעלי עניין.
- **מערך האפשרויות משתמש בנקודות-פסיק כמפרידי שורה.** טעות הקלדה עם פסיק במקום שוברת את הנוסחה בשקט עם שגיאת parsing מבלבלת. שומרים על הדפוס: שם פסיק ערך, אז נקודה-פסיק, אז הזוג הבא.
- **תאים ריקים בטווח הנתונים** מתעלמים מהם כברירת מחדל, אבל ערך אחד שאינו מספרי (כמו `#N/A` מ-lookup שבור) שובר את כל ה-sparkline. עוטפים את הנתונים ב-`IFERROR` (שיעור 9) לפני העברה.
- **שמות צבעים** רגישים לאותיות גדולות וקטנות במקרים מסוימים ולא עקביים בין charts. קודי hex (`"#4285F4"`) בטוחים יותר משמות (`"blue"` לעומת `"Blue"`).
- **ציר Y מוגדר כברירת מחדל לטווח הנתונים.** sparkline של ערכים 95-100 נראה זהה לאחד של 5-100 אלא אם מגדירים `ymin` ו-`ymax`. להשוואה ויזואלית עקבית בין שורות, נועלים את הגבולות.
- **Sparklines לא מתעדכנים אוטומטית עם conditional formatting.** הם מציירים על בסיס נתונים, לא על בסיס מצב עיצוב. אם רוצים "מגמות צבועות אדום מתחת לסף", מחשבים את הצבעים באפשרויות באופן פרוגרמטי.
- **טווח הנתונים יכול להיות עמודה או שורה** אבל לא רשת דו-ממדית. אם רוצים כמה סדרות, אי אפשר.

## נפוץ בשטח

- **עמודת מגמה לכל media buyer או לכל vertical** ב-dashboards. תא אחד, הקשר ויזואלי מיידי, ניתן לגרירה לאורך כל הרשימה.
- **סרגלי winloss לעקביות ROI.** ROI יומי כשורה של סימני ירוק/אדום, מסמנת media buyers לא עקביים בלי לזרוק מספרים.
- **sparkline של תקופה מול תקופה.** 30 הימים האחרונים של spend כ-chart זעיר אחד לכל שורה בדוח.
- **סרגלי מעקב יעדים.** sparkline מסוג bar שמראה אחוז התקדמות ליעד חודשי, עם `ymax` שמוגדר לערך היעד.
- **רצועת תוצאות A/B test.** Win/loss בין N זרועות test, צבועים ירוק/אדום, בתא בודד של סיכום הניסוי.
